# Hermes 技能自治理对齐记录

基线为 hermes-loop v0.3.2（`6ce02f45dc489a9fad4ab71f55d488b01ac294ed`）。DSH 宿主实测版本为 Desktop 0.2.2-rc.5。

| 使用场景 | DSH / OpenViking 实现 | 验证与边界 |
| --- | --- | --- |
| 会话自动触发和立即复盘 | 从已提交的会话事件计数，按轮次、工具调用、失败和纠正词触发。面板与 `/skill-review` 提供手动入口 | 隔离 DSH 实测轮次触发、模型提炼和同会话跨进程去重。实时任务在复盘结果写入账本前遇到进程中止，重新启动后可能重新调用模型 |
| 经验提炼 | 零工具模型调用输出一份结构化新建或修订提案，绑定会话证据。显式四行纠正走确定性解析 | 异步模型流与提案验证实测通过。每次复盘最多生成一份提案。v0.2.1 支持保留 YAML 元数据的多段正文补丁 |
| 预览、仅记录、审批与自动应用 | 影子模式保存差异。写入模式按受管私有 URI 纳入审批或自动应用。账本持有整包版本、审计状态和回读结果 | DSH 夹具验证预览、审批、回滚和设置持久化。原生 OpenViking 验证新建、撤回、补丁、附件与索引。跨写者原子性依赖服务端支持 |
| 日常管理面板 | DSH Web 设置通用页显示模式、阈值、模型、提案、历史、技能读取和记忆状态 | DSH Web 与隔离 Chrome 实测。待验证其他宿主和平台 |
| 使用统计与 Curator | 统计当前 profile 内成功读取的技能，维护最近使用、纳管和归档状态。每天巡检，30 天标记闲置，90 天归档 | 归档保留远端正文和附件，拦截当前 profile 的直接工具读取。远端检索、已加载的会话内容与其他客户端需要独立的状态同步能力 |
| 长期记忆 | 使用既有 OpenViking Memory 的原生召回、捕获、提交与工作区 peer，跟踪已提交的 Experience 结果出处 | 独立夹具验证两个工作区的不同 peer、原生调用序列和审计查询零新增请求。原生 OpenViking 0.5.5 隔离探针已验证提交、归档、异步提炼和 profile、preference 精确回读。启用账号演进后，隔离探针以确定性推理完成 case → trajectory → Experience。精确回读为 200，两个新工作区会话均以用户级 `self` 命中 |

测试命令和实测结果见 [NOTES.md](../NOTES.md)。
